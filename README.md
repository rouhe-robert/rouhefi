# rouhefi
Rouhe.fi website

## Technologies
This website has been implemented with React, Next.js, Bootstrap and Fontawesome

## Requirements
Use Node.js 20.9 or newer. The project now targets current Next.js releases, which no longer support older Node runtimes.

## Setting up
Copy content.json.example to content.json and fill the data in it so that the page has content.

## Run in development
npm run dev

## Run in production
npm run build
